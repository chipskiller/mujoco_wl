# 问题记录

## MuJoCo viewer 启动后不显示模型

- **现象**：`python -m mujoco.viewer test2.xml` 打开 viewer 但画面空白
- **原因**：MuJoCo 3.13.0 的 viewer CLI 必须用 `--mjcf=` 参数指定文件，直接传文件名会被忽略
- **解决**：
  ```bash
  python -m mujoco.viewer --mjcf=test2.xml
  ```
- **验证**：`python -m mujoco.viewer --helpfull` 查看支持的参数

## test2.py / test_control.py 运行后模型运动过快

- **现象**：打开 viewer 后模型运动速度异常快
- **根源**：Windows 上 `time.sleep()` 实际精度仅 ~15ms，而物理步长 `dt=0.01s`（10ms），直接 `time.sleep(dt - elapsed)` 经常睡不够甚至不睡
- **解决**：忙等待 + sleep 混合方式，sleep 只用于 >2ms 的大段时间，最后用忙等待精准收尾
  ```python
  while time.perf_counter() - step_start < dt:
      remaining = dt - (time.perf_counter() - step_start)
      if remaining > 0.002:              # >2ms: 用 sleep 省 CPU
          time.sleep(remaining * 0.9)    # 留 10% 余量
  ```

# 轮腿平衡闭环：整定与标定记录

> 对象：`b站_车奉朝_腿仿真/wheel_leg_mujoco`，LQR（上交文档 10 状态 × 4 控制）+ 腿长 PD。
> 下面每一条都是实测或原文推导结论，不是推测。

## 1. 初始姿态：双腿竖直 + 真实贴地

- **目标位形**：`θ = 0`、`L0 ≈ 0.209 m`，即 LQR 的线性化平衡点。
- **四个电机角**（由五连杆正解反推，实测 `L0L=0.2085 / L0R=0.2087 / θ≈0`）：
  - 右腿 `jAB = -0.2888`（右前）、`jAG = -1.0382`（右后）
  - 左腿 `jIJ = +0.2570`（左前）、`jIO = +1.0380`（左后）
- **被动关节不能随手置 0**：8 个被动关节（jGH/jBE/jEC/jCF/jJM/jMK/jKN/jOP）若给 0，4 个 `<connect>` 闭链约束初值被破坏，起步会被约束力弹飞。必须用高斯-牛顿迭代把约束残差解到 `< 1e-9`。
- **坑：不能用 `geom_rbound` 估最低点**
  - 现象：`qpos[2] = 0.2747`，而轮子实际离地 **0.1453 m**，整机悬空。
  - 原因：`geom_rbound` 是**包围球半径**，对细长连杆/机体网格会严重高估下沿。
  - 正确做法：用 `mj_geomDistance(m, d, g, floor_id, 10.0, None)` 求每个几何到地平面的真实最短距离，再 `qpos[2] -= gap`。修正后 `qpos[2] = 0.1547`，`ncon = 5`，轮子真正贴地。
  - 这个 bug 会让所有闭环测试失真：前 0.15 s 实际是 14.5 cm 自由落体。

## 2. 腿长 PD（F0 虚拟径向力）

- **F0 符号**（固定机体实测）：`F0 > 0 = 腿伸长（把机体顶起）`，`F0 < 0 = 腿收缩`。
  - 注意 `VMC.py` 里 "正=收缩" 的旧注释是错的。
- **腿长目标** `L_REF = 初始直立腿长`（启动时由 VMC 预热的 L0 取平均，约 0.2086 m），不再写死 0.21。
- **重力前馈** `F0_FF = 0.7 × 理论值`：
  - 理论值 = `14.546 kg × 9.81 / 2 = 71.3 N/腿`（机体 8.4 + 腿 2×2.751 + 轮 2×0.322）
  - 实际取 `0.7 × 71.3 ≈ 50 N`，剩余由 PD 补齐。
- **参数**：`KP_L = 800 N/m`、`KD_L = 40 N/(m/s)`。
- **重要关系**：空载（腿不受体重）时 PD 的静平衡点是
  `L0_eq = L_REF + F0_FF / KP_L`
  代入旧的 71 N 前馈得 `0.21 + 71/800 = 0.2988 m`，即腿会一直伸到 0.298 —— 说明前馈必须与"真正由腿承担的载荷"匹配。

## 3. VMC 数值微分的首帧冲击

- **现象**：首帧 `F0 = -16626 N`，关节力矩瞬间被 ctrlrange 钳到 `±20 Nm`。
- **原因**：`last_L0` 初值为 0，而 `d_L0 = (L0 - last_L0)/dt`，首次调用得到 `0.2085/0.0005 ≈ 417 m/s`。
- **修复**：
  1. `VMC.py` 的 `first_flag` 块里补 `self.last_L0 = self.L0`；
  2. `Simulation.py` 主循环前先用初始姿态跑一次 `vmc_calc_pos` 预热（顺带得到初始腿长作 `L_REF`）。

## 4. 髋力矩通道符号（T_b ↔ Tp ↔ θ_l）

**文档原文**（`上海交通大学RoboMaster2023平衡步兵控制系统开源/WBR_modeling.html`）：

```
*$\theta_{l,i}\ (i=l,r)$: 腿倾斜角（自然坐标系法向）
$s_{l,i}=R_w\theta_{w,i}+l_{w,i}sin\theta_{l,i}$              (2.3)
$R_w\theta_{w,l}=s_b-R_l\phi-l_lsin\theta_{l,l}$              (2.5)
```

由 (2.5) 移项：`s_b = R_w·θ_w + R_l·φ + l·sinθ_l`
→ **文档的 θ_l > 0 = 髋部在轮子前方（+s）**。刚性整体前倾时 θ_b 与 θ_l 必须同号。

**文档对 T_b 的符号**：`T_b: 腿部转矩（机体-腿）`，由 equ1 整理：
`(m_l·l_w·l_b − I_l)·θ̈ = (m_l·l_w + 0.5·m_b·l)·g·θ_l + T_b − T_w(1+l/R)`
系数 `m_l·l_w·l_b − I_l` 在 l=0.08~0.30 恒为负（l=0.21 时 = −0.124）
→ **T_b > 0 使 θ_l 增大 = 髋前移**。

**实测（重力关、机体位姿锁死、单独给 Tp）**：

| 测试 | 结果 | 含义 |
|---|---|---|
| 机体绕 +y 转 +0.15 | `euler[1]=+0.15`，上方轴 `(+0.149,0,+0.989)` | θ_b>0 = 机顶朝 +x(+s) |
| 右腿两电机 +0.03 | `θ_vmc −0.030`，轮子 x **+0.0064** | θ_vmc 减小 = 髋往 **−x** |
| 左腿两电机 +0.03 | `θ_vmc −0.030`，轮子 x **−0.0062** | θ_vmc 减小 = 髋往 **+x** |
| 右腿 `Tp=+1` | `θ_vmc 0 → −0.106` | Tp>0 使 θ_vmc 减小 |
| 左腿 `Tp=+1` | `θ_vmc +0.001 → −0.107` | Tp>0 使 θ_vmc 减小 |

**最终映射**：

```python
# 状态量（文档定义：θ > 0 = 髋在轮子前方）
state[4] = -vmc_l.theta      # theta_l_l
state[5] = -vmc_l.d_theta
state[6] = +vmc_r.theta      # theta_l_r
state[7] = +vmc_r.d_theta

# 髋力矩（T_b > 0 要髋前移）
vmc_l.Tp =  u[2]             # T_b_l
vmc_r.Tp = -u[3]             # T_b_r
```

> 结论：**状态量与力矩必须同时取这一套符号**。只翻其中一个都会让 K 的交叉项反向（`u_hip` 还耦合 θ_b 约 −10.7 Nm/rad、`u_w` 还耦合 θ_l 约 −4.8 Nm/rad）。

## 5. 轮力矩通道符号（T_w）

| 环节 | 结论 | 依据 |
|---|---|---|
| 文档 | `T_w > 0 = 前进（+s）` | K 中 `u_w = +3.97·θ_b`，θ_b>0(前倾) 时要往前开把轮子挪到身下 |
| XML 轴 | 右轮 `axis=(0,+1,0)`、左轮 `axis=(0,−1,0)` | `data.xaxis` 实测 |

## 6. 状态量 / 控制量定义

```
x = [s, dot_s, phi, dot_phi, theta_l_l, dot_theta_l_l, theta_l_r, dot_theta_l_r, theta_b, dot_theta_b]
     水平位移 水平速度 偏航 偏航角速度   左腿倾角   左腿角速度     右腿倾角   右腿角速度     机体俯仰  俯仰角速度

u = [T_w_l, T_w_r, T_b_l, T_b_r]
     左轮力矩 右轮力矩 左髋力矩 右髋力矩
```

- `s = qpos[0]`，`dot_s = qvel[0]`（不要用 `environment.py` 的 `d_x` 积分，轮径换算有误差）
- `theta_b = euler[1]`，`dot_theta_b = gyro[1]`
- 参考状态 `x_ref = None` → 全零，即"竖直、静止、偏航 0"
- 控制律 `u = -K(x - x_ref)` 与文档 (3.1) `u = K(x_d - x)` **数学等价，不反**

## 7. 全链路正方向（LQR → VMC → 执行器）

> 竖直站立位形（`qpos[2]=0.1547`）下逐级探针实测 + 锁体实验，不是推测。

### 7.1 链路总览

```
u = [T_w_l, T_w_r, T_b_l, T_b_r]              ← LQR 输出（文档坐标系）
     │        │        └──────┬───────┘
     │        │      Tp_l=+u[2], Tp_r=−u[3]          ← 翻转点②
     │        └──────────────► ctrl[4]=u[1], ctrl[5]=u[0]   ← 翻转点③
     ▼
F0（腿长 PD，径向） + Tp（切向） ──► τ = Jᵀ·[F0, Tp]ᵀ
                                        │
     ctrl[0]=右前  ctrl[1]=右后  ctrl[2]=左前  ctrl[3]=左后   ← 翻转点④
```

### 7.2 LQR 层（上交文档坐标系）

| 量 | 正方向 | 依据 |
|---|---|---|
| `s` / `dot_s` | 世界 +x（车头朝向） | — |
| `phi` / `dot_phi` | 绕世界 +z（俯视逆时针） | 欧拉角 ZYX |
| `theta_l_l` / `theta_l_r` | **髋在轮子前方** | 文档 (2.5) `s_b = R_wθ_w + R_lφ + l·sinθ_l` |
| `theta_b` / `dot_theta_b` | 机体顶端朝 +x（前倾） | 实测：绕 +y 转 0.15 → `euler[1]=+0.15`，上方轴 `(+0.149,0,+0.989)` |
| `T_w_l` / `T_w_r` | **前进（+x）** | K 行 0：`u_w = +3.97·θ_b`，前倾时要往前开盘轮 |
| `T_b_l` / `T_b_r` | **髋前移（θ_l 增大）** | equ1 系数 `m_l·l_w·l_b − I_l` 恒为负 |

### 7.3 VMC 层（腿部局部系，竖直位形实测）

| 量 | 右腿 | 左腿 | 正方向含义 |
|---|---|---|---|
| `phi1`（φ1 前摇臂） | +2.8798 | +2.8796 | 相对底盘 X 轴；调用时已加 π 零点偏移 |
| `phi4`（φ4 后摇臂） | +0.2618 | +0.2600 | 同上 |
| `L0` | 0.2087 | 0.2085 | 腿长 [m] |
| `d_L0` | — | — | **+ = 伸长** |
| `phi0` | +1.5708 (+90°) | +1.5698 | 腿竖直向下时 = 90° |
| `alpha` = π/2 − phi0 | 0 | +0.0010 | 0 = 腿竖直 |
| `theta` = π/2 − PitchR − phi0 | 0 | +0.0010 | 见下方说明 |

> `theta` 减小 = 脚(轮) 沿该腿**局部 +X** 方向移动：右腿局部 +X 对应世界 **+x**（髋相对轮后移，`θ_l_r` 减小），左腿局部 +X 对应世界 **−x**（髋相对轮前移，`θ_l_l` 增大）。
> 所以文档 θ_l 必须按腿镜像取号（翻转点①），不存在“theta 减小=髋前移”这种跨腿统一的说法。

> 内部还有一次 `PitchR = -pitch`；调用方对左腿传入 `pitch=-euler[1]`，即左腿实际是 `theta = π/2 − euler[1] − phi0`，右腿是 `theta = π/2 + euler[1] − phi0`。

**虚拟力（实测）**：

| 量 | 正方向 | 备注 |
|---|---|---|
| `F0` [N] | **+ = 腿伸长（把机体顶起）** | `VMC.py` 里 “正=收缩” 的注释已过时，以实测为准 |
| `Tp` [Nm] | **+ = theta_vmc 减小**（两腿同号同向，1 Nm → −0.106 rad） | 注释 “正=逆时针” 是局部系说法，跨腿不可直接套用 |

**雅可比拆分**（站立位形实测 `j11=−0.1416, j12=+0.5, j21=+0.1416, j22=+0.5`）：

```
τ_front(φ1) = j11·F0 + j12·Tp = −0.1416·F0 + 0.5·Tp
τ_rear (φ4) = j21·F0 + j22·Tp = +0.1416·F0 + 0.5·Tp
```

即 `F0` 产生**前后电机反号**力矩（纯伸缩），`Tp` 产生**前后电机同号**力矩（纯摆动）。
索引：`torque_set[1]` = φ1 电机（前摇臂），`torque_set[0]` = φ4 电机（后摇臂）。

### 7.4 执行器层（MuJoCo，gainprm=1 时 ctrl 即力矩）

| ctrl | 关节 | 来源 | 世界轴（站立位形实测） | 限幅 |
|---|---|---|---|---|
| `ctrl[0]` | jAB 右前 | `vmc_r.torque_set[1]` | (0, **−1**, 0) | ±20 Nm |
| `ctrl[1]` | jAG 右后 | `vmc_r.torque_set[0]` | (0, **−1**, 0) | ±20 Nm |
| `ctrl[2]` | jIJ 左前 | `vmc_l.torque_set[0]` | (0, **+1**, 0) | ±20 Nm |
| `ctrl[3]` | jIO 左后 | `vmc_l.torque_set[1]` | (0, **+1**, 0) | ±20 Nm |
| `ctrl[4]` | 右轮 | `u[1]`=`T_w_r`，gainprm **+1** | (0, **+1**, 0) | ±4 Nm |
| `ctrl[5]` | 左轮 | `u[0]`=`T_w_l`，gainprm **−1** | (0, **−1**, 0) | ±4 Nm |

轮子实测：`ctrl[4]=+1 → qvel=+56.2`、`ctrl[5]=+1 → qvel=−56.6`，两者世界角速度都绕 **+y**，都滚向 **+x** ⇒ `ctrl` 正 = 前进。

关节输入还带标定偏移（`environment.py`）：`+0.027`(AB)、`+1.3`(AG)、`+0.003`(IJ)、`−1.3`(IO)，`robot.joint_pos` ≠ 原始 `qpos`。

### 7.5 四处翻转点

| # | 位置 | 规则 | 原因 |
|---|---|---|---|
| ① | 状态组装 | `θ_l_l = −vmc_l.theta`；`θ_l_r = +vmc_r.theta` | 左右腿物理镜像：同样 +0.03 电机角，右腿轮子走 +x、左腿走 −x |
| ② | 髋力矩 | `Tp_l = +u[2]`；`Tp_r = −u[3]` | `Tp>0` 使 theta_vmc 减小，配合 ① 才使文档 θ_l 同向增大 |
| ③ | 轮力矩 | `wheel_torque = [u[1], u[0]]` | `u` 顺序 [左,右]，`ctrl[4..5]` 顺序 [右,左] |
| ④ | 左腿关节重排 | `[右前,右后,左前,左后] = [vr.ts1, vr.ts0, vl.ts0, vl.ts1]` | 左腿 φ1 接 **jIO（左后）**、φ4 接 **jIJ（左前）**，索引交叉 |

### 7.6 单指令自检

- `T_b_l = +1` → `Tp_l = +1` → theta_vmc 减小 → 文档 `θ_l_l` 增大 ⇒ **左腿髋前移**。
- `T_b_r = +1` → `Tp_r = −1` → theta_vmc 增大 → 文档 `θ_l_r` 增大 ⇒ **右腿髋前移**。
- 结论：**同号 `T_b` 在两条腿上产生同一个文档方向（髋前移）**，镜像已在 ② 中抵消。
- `T_w_l = T_w_r = +1` → `ctrl[4]=ctrl[5]=+1` → 两轮都滚向 +x ⇒ **前进**。

> 反例（曾经的错误）：只翻状态不翻力矩（或反之），`u_hip` 与 `θ_b` 的交叉耦合（−10.7 Nm/rad）会让髋力矩与俯仰反馈互相打架，0.25 s 内翻倒。
