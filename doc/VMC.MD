# 关于从关节空间映射到工作空间
> 速度关系→雅可比矩阵→力矩关系


## 为什么速度关系得到的雅可比矩阵可以直接用来描述力矩关系

### 虚功原理 (Principle of Virtual Work)

#### 1. 速度映射：雅可比矩阵的定义

雅可比矩阵 J 描述的是**关节空间速度**到**任务空间速度**的线性映射：

```
v = J · q̇

其中:
  q̇  — 关节速度向量 (rad/s),  [φ1̇, φ4̇]^T
  v  — 任务空间速度,           [L0̇, φ0̇]^T  (腿长的变化速率 + 腿角度的变化速率)
  J  — 雅可比矩阵 (2×2),        J[i][j] = ∂v_i/∂q̇_j
```

这里完全没有涉及"力"——J 纯粹从几何/运动学推导出来。

#### 2. 功率守恒（虚功原理的核心）

考虑一个无穷小时间 `dt`，从做功（能量）的角度切入：

```
电机做功:  dW_motor = τ · dq       (力矩 × 无穷小角位移)
脚端做功:  dW_foot  = F · dx       (力   × 无穷小线位移)
```

**能量守恒**要求：机构内部没有储能/耗能（理想约束），则输入功率 ≡ 输出功率：

```
τ · dq  =  F · dx        ← 无穷小位移层面
```

两边同时除以 `dt`：

```
τ · (dq/dt)  =  F · (dx/dt)
τ · q̇        =  F · v      ← 功率层面 (力矩×角速度 = 力×线速度)
```

**这一步已经把微积分做完了**——`dx/dt = v` 就是求导，但这个求导已经隐藏在"速度"这个概念里，不需要你手动做。

#### 3. 代入雅可比，消去 q̇

将 `v = J · q̇` 代入功率等式：

```
τ^T · q̇  =  F^T · (J · q̇)
τ^T · q̇  =  (F^T · J) · q̇
```

因为这对**任意** `q̇` 都成立（电机无论快慢，这个关系都成立），所以：

```
τ^T  =  F^T · J
```

转置：

```
τ  =  J^T · F
```

#### 4. 结论

```
┌─────────────────────────────────────────────────────┐
│  速度关系:   v  =  J  · q̇      (J 前乘关节速度)     │
│  力矩关系:   τ  =  J^T · F      (J^T 前乘虚拟力)    │
│                                                     │
│  同一个 J，只需转置，就从"速度映射"变成"力映射"。    │
│  这源于功率守恒 (P=τ·q̇=F·v)，与微积分无关。          │
└─────────────────────────────────────────────────────┘
```

#### 5. 在本项目中的具体形式

五连杆等价模型中，J 是 2×2 矩阵：

```
⎡ L0̇ ⎤   ⎡ j11  j12 ⎤ ⎡ φ1̇ ⎤
⎢     ⎥ = ⎢          ⎥·⎢     ⎥      (速度: 电机角→脚运动)
⎣ φ0̇ ⎦   ⎣ j21  j22 ⎦ ⎣ φ4̇ ⎦

⎡ τ_front ⎤   ⎡ j11  j21 ⎤ ⎡ F0  ⎤
⎢         ⎥ = ⎢          ⎥·⎢     ⎥  (力矩: 虚拟力→电机力矩)
⎣ τ_rear  ⎦   ⎣ j12  j22 ⎦ ⎣ Tp  ⎦
```
